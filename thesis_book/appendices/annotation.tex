%       directly to the CSV is overwritten on the next run.
%
%   labels_{ds}_dropped.csv
%       An input to the histogram rather than an archive: synthesize_census.py
%       merges its rows into the totals (cwq: 157 + 1 + 15 = 173). Nothing
%       regenerates it, because dump_failure_packets.py writes it only at the
%       moment a row leaves the population; once the census is fully labelled a
%       re-run will not recreate it. If it is lost, recover it from git history.
%
%   sampling_manifest.json
%       Written but never read back. Its labels_carried, to_read and dropped
%       fields are progress counters that reach 157/0/0 when annotation
%       completes. The thesis cites only population_wrong, population_hedge,
%       n_skipped and mode, which are stable across re-runs.
%
%   synthesize_census_log.txt, thesis_numbers.json
%       Outputs; regenerated rather than edited.
%
