% The board's objection was to the CONTENTS, not to the writing: at the
% report class's default tocdepth of 2 the table of contents listed all
% 105 sections and all 143 subsections and ran to eight pages (iv-xi) for
% a 185-page book. Listing sections only takes it to 129 entries.
%
% secnumdepth is deliberately NOT lowered with it. Subsections keep their
% numbers and their headings on the page, and every \Cref to one still
% resolves -- the thesis cross-references subsections heavily, and the
% deck and the checker cite them by number. Only the front-matter listing
% gets shorter; nothing is removed from the body.
\setcounter{tocdepth}{1}

% For index creation, comment this out if you do not want to create an
% index
\makeindex[intoc]

% The appendices are bound as a separate volume,
% thesis_book_0421052099_appendices.tex, and are read here for their labels
% only: nothing of that file is typeset in this one. The two documents each
% read the other's .aux, so no appendix number is transcribed by hand and none
% can go stale, but the pair has to be built twice over to settle --
% scripts/build_thesis.py does that. A reference printing as "??" means the
% appendix volume has not been built since its last structural change.
% The second optional argument, "nocite", is what keeps the import to labels.
% Without it xr also replays the other document's \bibcite lines, and the two
% volumes cite two works in common -- the sentence-encoder paper and the
% hallucination survey -- so both keys would be defined twice and a \cite here
% could pick up the appendix volume's numbering for them. The first optional
% argument is the label prefix, left empty on purpose: with it empty every
% \Cref{app:...} already written in these chapters keeps working untouched.
\usepackage{xr}
\externaldocument[][nocite]{thesis_book_0421052099_appendices}

% Every appendix reference is now a reference out of this document. Two
% consequences are handled here.
%
% It must not be a hyperlink. The destination is in a different PDF, so
% hyperref would colour it like a live link and do nothing on click, and
% pdfTeX would warn once per reference about the missing destination.
% cleveref passes the hyperlink's open and close as #2 and #3; a format that
% omits them keeps the number and drops the link.
%
% And it must read as an appendix. The companion volume puts its sections
% under the "appendix" type as well as its chapters, so a label from it
% renders "Appendix E.3" where one from this volume renders "Section 5.3".
% The reference alone therefore says which volume it lands in. Two references
% escape the scheme because they name appendix TABLES, a type this volume also
% uses: \Cref{tab:census} and \Cref{tab:census-pop} are written \Cref* at the
% site instead, and their lettered numbers do the same work.
% \crefname first and \crefformat second, in that order and not the reverse:
% \crefname sets every form of the name at once, the plural and range forms
% included, and would put the hyperlink back if it ran last. This document has
% no grouped appendix reference today, so only the single forms are stripped;
% a grouped one added later would be typeset as a live link and pdfTeX would
% say so, which is the failure this ordering leaves visible rather than
% silent.
\crefname{appendix}{Appendix}{Appendices}
\crefformat{appendix}{Appendix~#1}
\Crefformat{appendix}{Appendix~#1}
