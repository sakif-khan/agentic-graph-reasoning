\noindent Seven templates constitute the whole of AGR's interface to the
language model, and six serve the baselines: one for the parametric
control, one shared by the two static retrieval baselines, and four
belonging to the reimplemented agentic baseline. All thirteen are
reproduced here verbatim from the source that sends them, in the order a
question encounters them, by a script that reads the code
(\texttt{scripts/build\_paper\_supplement.py} in the repository named in
the paper's data-availability statement). No template carries a
configuration constant, so one cached response serves every condition of
a sweep; budgets are counters in code rather than instructions, and the
evaluator's remaining depth and backtracks are the only budget figures any
prompt carries. Every call asks for JSON against a schema stated in the
code beside the template.
