% ------------------------------- 1 -----------------------------------
\begin{column}{0.229\paperwidth}

\begin{block}{Problem}
Large language models answer factual questions fluently --- and sound just
as fluent when they do not hold the fact.
\vskip0.45em
\lead{Retrieval-Augmented Generation} retrieves \emph{once}, before any
reasoning starts, so a multi-hop question must be answered from whatever
that first query returned. Graph-navigating systems do better by
interleaving retrieval with reasoning.
\vskip0.45em
But all of them emit whatever the final generation call produces.
\lead{Nothing checks what the answer asserts before the user sees it.}
\end{block}

\begin{block}{The gap, measured}
A parametric LLM control, on the same questions, asserted entities that
\emph{do not exist anywhere in the graph}:
\vskip0.55em
\stat{22.1\,\%}{$221$ of $1{,}001$ asserted entities ungrounded ---
  and stated without a hedge}
\vskip0.55em
Retrieval reduces this without closing it. Only a system that checks its
own claims against what it actually traversed can.
\end{block}

\begin{block}{Research questions}
\begin{itemize}\setlength\itemsep{0.4em}
  \item[\textbf{RQ1}] Does agentic navigation improve multi-hop accuracy
    --- and does the advantage \emph{grow} with hop count?
  \item[\textbf{RQ2}] What does pre-generation verification contribute
    beyond navigation alone?
  \item[\textbf{RQ3}] Which components earn their cost, in accuracy and
    in tokens?
\end{itemize}
\end{block}

\end{column}

% ------------------------------- 2 -----------------------------------
\begin{column}{0.229\paperwidth}

\begin{block}{Method: AGR}
An \lead{explicit state machine}, not a prompt loop. Six nodes; the model
is consulted only at decision points, and every cycle passes a router
checking a monotone counter --- so termination never depends on the model
cooperating.
\vskip0.7em
\centering
% Node width is set from the widest label: "Backtracker" in bold at this
% size needs 44mm, and 38mm overran it by 18.5pt -- which is what put the
% word on top of the Evaluator box on the first pass. The left-hand loops
% are run out far enough that their labels clear the boxes rather than
% sitting against them.
\begin{tikzpicture}[
  node distance=15mm,
  box/.style={draw=cseGreen, very thick, rounded corners=2pt,
    minimum height=14mm, fill=cseGreen!8, text width=46mm,
    align=center, font=\small\bfseries},
  vbox/.style={box, draw=agrAGR, fill=agrAGR!14},
  term/.style={draw=black!45, circle, inner sep=2pt, font=\scriptsize,
    fill=black!6},
  flow/.style={-{Stealth[length=3mm]}, thick, draw=black!62},
  lbl/.style={font=\scriptsize, inner sep=1.5pt, fill=white}]
  \node[term]                     (start) {START};
  \node[box, below=9mm of start]  (plan)  {Planner};
  \node[box, below=of plan]       (expl)  {Explorer};
  \node[box, below=of expl]       (eval)  {Evaluator};
  \node[vbox, below=of eval]      (ver)   {Verifier};
  \node[box, below=of ver]        (ans)   {Answerer};
  \node[box, right=30mm of eval]  (back)  {Backtracker};
  \draw[flow] (start) -- (plan);
  \draw[flow] (plan)  -- (expl);
  \draw[flow] (expl)  -- (eval);
  \draw[flow] (eval)  -- node[lbl] {answer} (ver);
  \draw[flow] (ver)   -- node[lbl] {grounded} (ans);
  \draw[flow] (eval.east) -- node[lbl] {backtrack} (back.west);
  \draw[flow] (back.north) |- (expl.east);
  \draw[flow] (eval.west) -- ++(-17mm,0)
    node[lbl, above, pos=0.62] {continue} |- (expl.west);
  \draw[flow] (ver.west) -- ++(-28mm,0)
    node[lbl, below, pos=0.62] {retry} |- ([yshift=-3mm] expl.west);
  \begin{scope}[on background layer]
    \node[draw=black!35, dashed, thick, rounded corners, inner sep=2.5mm,
          fit=(expl)(eval)] {};
  \end{scope}
\end{tikzpicture}
\vskip0.5em
{\small The dashed box is the search loop: a \lead{guided beam} of width~3
over candidate edges, scored by embedding similarity blended with a model
judgement of the active sub-objective.\par}
\end{block}

\begin{block}{Contribution: Structural Verification}
Before the answer is emitted, the draft is split into \lead{atomic claims}
and each is checked against \emph{the triples the agent actually
traversed} --- not against the model's own belief.
\vskip0.45em
\begin{itemize}\setlength\itemsep{0.32em}
  \item Grounded claims return \textbf{paired with their supporting
    triples}.
  \item Claims that cannot be grounded are re-explored, then withdrawn.
  \item The system therefore \textbf{hedges rather than asserts} when the
    graph does not support it.
\end{itemize}
\end{block}

\end{column}

\begin{block}{Results}
Five systems, \lead{one frozen backbone}, one shared call budget, one
environment of $2.59$M entities and $8.31$M triples --- so any difference
is architecture, not model capacity. $400$ certified questions per
dataset.

\begin{column}{0.229\paperwidth}

\begin{block}{Key findings}
\vskip0.15em
\stat{0 / 1{,}709}{asserted entities ungrounded, both datasets pooled ---
  AGR never names an entity absent from the graph}
\vskip0.85em
\stat{29\,\% / 44\,\%}{of questions on which the agentic baseline exhausts
  the shared call budget. AGR's call budget \emph{never} binds}
\vskip0.8em
{\small \lead{An honest caveat.} On the questions Think-on-Graph does
finish, it leads AGR. The whole aggregate margin comes from the ones it
cannot afford to finish --- which is the finding, not a footnote.\par}
\vskip0.4em
{\small \lead{Verification does not raise accuracy.} It converts silent
error into an explicit hedge and attaches evidence. Its contribution is
auditability, and this poster says so because that is what was
measured.\par}
\end{block}

\begin{block}{Conclusion}
\begin{itemize}\setlength\itemsep{0.35em}
  \item Interleaving retrieval with reasoning, under \emph{explicit
    budgets}, beats both one-shot retrieval and unbounded beam search.
  \item Checking claims against the traversed subgraph before emitting
    gives an answer that arrives \textbf{with its evidence}.
  \item Everything here is \lead{training-free}: one frozen backbone, no
    fine-tuning, no gradient step.
  \item Every reported number is regenerated from committed run records,
    and every question identifier is published.
\end{itemize}
\end{block}
